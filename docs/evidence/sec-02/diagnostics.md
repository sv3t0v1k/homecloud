# Диагностические инструменты SEC-02

Инструменты предназначены исключительно для ручного анализа
результатов сканирования и подготовки security review.

## gosu-applicability.py

- Проверяет SHA256 переданного бинарника.
- Анализирует предоставленные символы и сведения Go advisory.
- Отсутствие пакета или символа является кандидатом для review,
  а не самостоятельным доказательством неприменимости CVE.
- Связь входных отчётов с конкретным бинарником требует
  отдельной проверки происхождения доказательств.
- Release disposition: NONE.

## security-inventory.py

- Инвентаризирует HIGH и CRITICAL в предоставленных отчётах.
- Не гарантирует полноту набора исходных отчётов.
- Проверка environment evidence выполняется при его наличии.
- Классификация владельца и домена является диагностической.
- Применимость и достижимость уязвимостей остаются UNVERIFIED.

## Границы использования

- Инструменты не заменяют Trivy, scan-policy.py,
  policy-coverage.py или release-квалификацию.
- Не разрешается использовать их вывод для исключения CVE,
  изменения severity gate или разрешения публикации RELEASE.
- Историческая qualification.json сохраняется без изменений.
- Четыре диагностических теста, ранее выполненные на untracked
  исходниках, закреплены отдельным коммитом.
- Регрессия диагностических инструментов: 4/4 PASS.

Формальная квалификация релиза и независимый review обязательны.
